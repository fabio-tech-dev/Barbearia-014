# 014Barbershop — Landing page
Abrir `index.html` no navegador (ou publicar a pasta em Netlify/Vercel/GitHub Pages).
Tudo se edita em `js/config.js`: link do Booksy, Instagram, morada, serviços, fotos e equipa.
Cores: variáveis no topo de `css/style.css`. Fotos: substituir ficheiros em `assets/img/` (ou mudar o caminho no config).
Equipa: `visible:false` oculta um perfil; preencher role/bio/photo/instagram quando houver dados.
Domínio: ativar a linha `canonical` em `index.html`.
